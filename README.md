# Sunshine

App web personal de seguimiento diario: rutina por momentos, lectura, estudio, entrenamiento, metas y avisos para el calendario.

- Se instala en el teléfono desde el navegador (en iPhone: Safari, Compartir, Agregar a inicio).
- Funciona sin conexión.
- Los datos viven solo en el teléfono. Este repositorio no contiene datos personales: la rutina y el registro se cargan desde un archivo de respaldo.
- El respaldo se guarda y se carga en Ajustes, Respaldo.

Todo está en `index.html`. No hay paso de compilación.
